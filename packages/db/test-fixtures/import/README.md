# Import test fixtures (M9-01)

Made-up files for testing `pnpm db:import`. **No real guest, staff or card data is here**: phone numbers are 555 numbers, emails use example.com, and the only card number is Stripe's public test number 4242 4242 4242 4242, there to prove the tool refuses it.

- `rehearsal/` is the demo seed's 11 bookings, 17 guests, 127-line menu and team, written in an old booking system's style. It is generated by `buildRehearsalExport` in `src/import/rehearsal.ts`; a unit test keeps the two in step.
- `sample/` covers what the seed doesn't: a JSON file, money in cents, consents (opt-ins and an opt-out) and nightly totals.
- `refused/` holds files the tool must refuse before anything loads: a PIN column, a card-number column, and a card number hidden in a notes column.

West 4's real export files are not here and must never be committed.
